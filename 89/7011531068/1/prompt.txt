# 4. CI DURATION AND FLAKE MITIGATION

## Explicit timeouts
- Job `timeout-minutes`: pr-risk `test-proxied-cmd` 20, `test-embedded-conformance` 35, `test-server-storage` 20, `test-nix` 10; main `main-linux-integration-*` 30, `test-proxied-cmd` 20, `test-embedded-conformance` 35, `test-nix` 10; nix-build 10; regression 25; nightly 45; migration-test 45; cross-version smoke 15; proxied-local-smoke 25; update-vendor-hash 15; ci-measurements 20–60.
- Go-level: `contract-corpus` `-timeout 30m` (comment: package "runs well past `go test`'s 10m default; without it a slow runner reports a panic, not a verdict"); embedded storage/conformance `-test.timeout=30m` under a 35m job timeout, deliberately so a stall dumps goroutines before Actions kills the job; integration shards `-timeout=30m`; regression `-timeout=20m`; nightly `-timeout=30m`; proxied-local-smoke `-test.timeout 15m`; golangci-lint `--timeout=5m`; local `scripts/test.sh` default 3m, `REGRESSION_TIMEOUT ?= 20m`, `make bench` 30m.

## Documented / commented durations
- `contract-corpus` comment: "~10 min: each test builds an isolated Dolt-backed workspace."
- `test-embedded-conformance` comment: combined suite "has exceeded 30m under runner variance; each half currently takes ~15m."
- `engdocs/CI_CLEANUP_PLAN.md` measured samples: `pr-core` 593s job / 577s command; `pr-lint` 211s (143s lint + 54s tool install); `pr-policy` 91s (53s docs-binary build); existing Linux short test job 607s; macOS short 383s; Windows smoke 237s; embedded tail — storage 355s, cmd 19/20 403s, cmd 7/20 387s, cmd 4/20 334s; cross-version-smoke 171s; npm-package 212s; mcp-package 264s; linux-integration-coverage 856s. Stated budget: "wall-clock target is about 25 minutes total."
- `engdocs/TESTING.md`: local full-suite compilation ~180s dominates.

## Flake mitigation present
- `fail-fast: false` on every matrix (pr windows-make-shell; main test/integration/embedded/proxied; pr-risk proxied/conformance/embedded; cross-version smoke; all measurement matrices) — one shard failing does not cancel siblings.
- `continue-on-error: true` on all Codecov uploads (main.yml lines 478, 487; nightly.yml 101) plus `fail_ci_if_error: false`; coverage is explicitly non-blocking ("Coverage Signal Policy" in engdocs/TESTING.md).
- Pre-pulling `dolthub/dolt-sql-server:2.2.0` in `test-domain-uow`, `contract-corpus`, `test-server-storage`, `test-proxied-cmd`, and `regression` — comments state this converts silent self-skips into real runs, and in regression.yml specifically avoids "the embedded Dolt with HOME=&lt;tmpdir&gt; ... known cleanup race (TestCreateWithParentFlag TempDir RemoveAll 'directory not empty' flake)".
- Non-race `/tmp/bd-proxied` subprocess binary built alongside the `-race` test binary purely to keep proxied runs inside the timeout.
- Binary caches: `actions/cache` on `~/.cache/beads-regression` in regression, cross-version-smoke, migration-test.
- Concurrency `cancel-in-progress: true` on pr, pr-risk, main, conformance, cross-version-smoke, docs-mintlify, docs-autofix (but `cancel-in-progress: false` on update-vendor-hash and the Pages deploy).
- `nightly`/measurement workflows were changed to "continue independent commands after a failure and exit nonzero at the end, so later samples still collect lint timing when core flakes."
- `ci-gate` treats `cancelled` as failure; `skipped` is accepted only for the explicitly enumerated tier/event cases.
- **No retry actions anywhere** — no `nick-fields/retry`, no `max_attempts`, no `-count=N` reruns. Retry is manual re-run only.</result>
